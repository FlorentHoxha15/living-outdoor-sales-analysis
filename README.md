Living Outdoor Sales Analysis
Project Overview

This Power BI project analyzes sales data from a fictional outdoor retail company.

The goal was to identify top-performing products, sales trends, and regional performance through interactive dashboards.

Tools Used
Power BI
Power Query
DAX
Excel
Key Findings
Personal Accessories generated the highest revenue.
Europe was the strongest market.
Eyewear and Watches were among the best-performing products.
Sales performance varied significantly across countries.
Revenue increased over time before declining in the latest period.
